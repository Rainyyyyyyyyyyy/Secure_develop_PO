## Тестирование

---

### Некорректные входные данные [P0]

-  **0.1** Пароль длиной менее 8 или более 32 символов
-  **0.2** Указан путь к файлу вместо папки
-  **0.3** Указан путь к несуществующей папке
-  **0.4** Указан пустой путь
-  **0.5** Указан путь к рабочей папке (папке с исполняемым файлом)

---

### Без вложенных папок [P1]

-  **1** Шифрование пустой папки
-  **2** Шифрование папки с пустыми и непустыми файлами
-  **3** Шифрование папки с пустыми/непустыми файлами + ярлыками на них
-  **4** Шифрование папки с файлами, ярлыками на файлы и ярлыками на эти ярлыки

---

### С вложенными папками без файлов [P2]

-  **5** Шифрование папки с пустыми подпапками
-  **6** Шифрование папки с подпапками и ярлыками на эти подпапки

---

### С вложенными папками с пустыми файлами [P3]

-  **7** Шифрование папки: пустые подпапки + подпапки с пустыми файлами
-  **8** Шифрование папки: пустые подпапки + подпапки с пустыми файлами + ярлыки на них

---

### С вложенными папками с пустыми и непустыми файлами [P4]

-  **9** Шифрование папки: пустые подпапки + подпапки с пустыми и непустыми файлами
-  **10** Шифрование папки: файлы (пустые/непустые) + подпапки с файлами (пустые/непустые)

---

### С файлами, имеющими системные атрибуты [P5]

-  **11** Шифрование папки с файлами, имеющими системный атрибут
-  **12** Шифрование папки с подпапками, имеющими системный атрибут

---

### Со скрытыми файлами [P6]

-  **13** Шифрование папки со скрытыми файлами
-  **14** Шифрование папки с подпапками, содержащими скрытые файлы

---

### Со скрытыми подпапками [P7]

-  **15** Шифрование скрытой папки
-  **16** Шифрование папки со скрытыми подпапками
